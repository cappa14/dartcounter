# DartVision

DartVision is een lokale dart-webapp.

## Inhoud
- Wedstrijd: 301 / 501 / 701
- Rond de Klok
- Score invoeren
- Dartbord invoer
- Laatste pijl verwijderen
- Undo
- Actieve speler met ▶
- Geen groot dubbel scorevak tijdens wedstrijd

## Starten lokaal
```bash
npm install
npm run dev
```
